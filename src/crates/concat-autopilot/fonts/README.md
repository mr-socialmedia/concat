# Caption fonts

Three Arabic faces, bundled so captions look right without anything to install. All are under the
SIL Open Font License 1.1, whose texts sit beside the fonts (`OFL-*.txt`), and none declares a
Reserved Font Name on its copyright line.

| File | Family | Weight | Source |
|---|---|---|---|
| `Cairo-Black.ttf` | Cairo | 900 | Instanced at weight 900 from the variable `Cairo[slnt,wght].ttf` in github.com/google/fonts (the engine ignores a variable font's weight axis, so a static face is needed) |
| `Tajawal-ExtraBold.ttf` | Tajawal | 800 | github.com/google/fonts, unmodified |
| `Almarai-ExtraBold.ttf` | Almarai | 800 | github.com/google/fonts, unmodified |

`docs/captions-fonts.png` shows the same caption in each.
